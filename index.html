The workflow

公開までの4ステップ

自分のファイルを追加する小さな作業を通して、実際のチーム開発と同じ流れを体験します。

01 / CLONE

手元にコピー

公開リポジトリを自分のPCにcloneします。

02 / BRANCH

自分の枝で編集

mainから作業ブランチを作り、自己紹介HTMLを追加します。

03 / PULL REQUEST

レビューを依頼

変更をpushしてPRを作り、仲間に確認してもらいます。

04 / MERGE

サイトに反映

PRがmainにマージされると、公開サイトにも反映されます。
