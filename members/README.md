# 自己紹介ページの置き場所

参加者は `profile-template.html` をコピーし、このフォルダに `<GitHubユーザー名>.html` という名前で保存してください。例: `members/octocat.html`。

自分のファイルだけを編集し、作業ブランチから Pull Request を作ってください。マージ後の公開 URL は `https://que-dotcom.github.io/practice-github/members/<GitHubユーザー名>.html` です。

本名、住所、電話番号、学校・勤務先など、公開したくない情報は書かないでください。
